隐私政策

最后更新日期：2026年11月19日

A股市场日报（以下简称"本服务"）高度重视用户隐私保护。本隐私政策说明我们如何收集、使用和保护您的信息。

一、信息收集

本服务为自动化市场数据报告生成与推送工具，不主动收集用户的个人身份信息（如姓名、手机号、身份证号等）。

在运行过程中可能涉及：

  • 微博 OAuth 授权信息：用于调用微博开放平台 API 发布内容。Access Token 存储在本地加密配置中，不上传至第三方服务器。
  • 市场行情数据：从东方财富、新浪财经等公开数据源获取，不涉及用户个人数据。
  • 飞书推送配置：用于向指定飞书群/用户推送日报，仅存储必要的机器人 Webhook 地址和接收者标识。

二、信息使用

收集的配置信息仅用于：

  • 驱动每日市场日报的自动生成与多端发布
  • 调用微博开放平台 API 发布图文内容
  • 通过飞书机器人推送 PDF 报告

不会将任何配置信息或报告数据出售、转让或分享给第三方。

三、信息存储

  • 微博 Access Token 等凭据存储于本地加密配置文件，仅运行日报生成脚本时读取。
  • 市场数据缓存为临时文件，定期清理。
  • 本服务无外部数据库，所有数据存于用户控制的本地环境。

四、信息安全

我们采取合理的技术措施保护信息免遭未经授权的访问、修改或泄露，包括：

  • 敏感凭据本地加密存储
  • 微博 API 通信使用 HTTPS 加密传输
  • OAuth 2.0 标准授权流程

五、免责声明

本服务输出的市场日报内容仅供参考，不构成任何投资建议。使用者应独立判断并承担投资风险。报告中的市场数据来源于公开接口，我们不对数据的准确性和完整性做出保证。

六、政策更新

我们可能不时更新本隐私政策。更新后将在本页面发布最新版本。

七、联系方式
